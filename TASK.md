# Отелло (Реверси) — требования к Java Core игре

## Основные правила

1. Поле `n × n` — квадратное, чётный `n >= 4`. По умолчанию `n = 8`. Начальное положение: `WHITE` на `(n/2-1, n/2-1)` и `(n/2, n/2)`, `BLACK` на `(n/2-1, n/2)` и `(n/2, n/2-1)`. Первым ходит `BLACK`. Координаты API отсчитываются от нуля.
2. Игрок может поставить фишку только в пустую клетку, если по крайней мере в одном из восьми направлений от неё расположена одна или несколько подряд фишек соперника, после которых стоит своя фишка. Захваченные в каждом направлении фишки превращаются в фишки текущего игрока.
3. Если у соперника после сделанного хода нет допустимых ходов, очередь остаётся у текущего игрока. Пропуск автоматический, в `history()` не записывается.
4. Когда ни у кого нет допустимых ходов (не обязательно при полном поле), сравниваются количества фишек. Победа чёрных, победа белых либо ничья.
5. Некорректный ход возвращает `false`, не меняя доску, историю или очередь. Данные истории и массива доски выдаются через защитные копии.

## Типы данных

- `enum Mark { BLACK, WHITE, EMPTY }`
- `enum GameState { BLACK_TURN, WHITE_TURN, BLACK_WON, WHITE_WON, DRAW }`
- `record Move(int row, int col, Mark mark)`

## Board

- `Board()`, `Board(int size)`, `Board(Board other)` — создание начальной доски или её глубокой копии. Нечётный `size` и значения меньше `4` приводят к `IllegalArgumentException` с сообщением `Board size must be even and at least 4 and divided by two without a remainder`.
- `int size()`, `Mark[][] toArray()` — размер и независимая копия клеток.
- `boolean place(int row, int col, Mark mark)` — выполнить разрешённый правилами Reversi захват с переворотом всех цепочек; `false` при невалидной постановке. Очередность и конец партии не проверяет.
- `int[][] availableMoves(Mark mark)` — координаты допустимых постановок заданного игрока, отсортированные по строке и столбцу.
- `boolean full()`, `int count(Mark mark)` — заполненность и количество клеток заданной метки.
- Внутренние методы `flippedCells`, `undo`, `getCell` используются игровой моделью и пакетными тестами.

## Game

- `Game()`, `Game(int size)`, `Game(Game other)` — новая партия и независимая копия.
- `Board board()`, `Move[] history()`, `GameState state()` — снимки доски и истории, состояние игры.
- `Mark currentPlayer()` — текущая метка, либо `EMPTY` после завершения партии.
- `int[][] availableMoves()` — допустимые ходы текущего игрока; при завершении игры — пустой массив.
- `int score(Mark mark)` — число фишек данного игрока.
- `boolean apply(Move move)` — проверка очереди, законности и окончания игры; выполнение хода, сохранение перевёрнутых позиций, обновление состояния.
- `int[][] lastFlipped()` — копия массива захваченных клеток при последнем принятом ходе.
- `boolean undoLast()` — откатить последний ход со всеми переворотами, восстановить предыдущую очередь и статус; `false` при пустой истории.

## Консоль

- `Main` начинает работу с приветствия `Отелло (Реверси).` и поддерживает двух игроков. Перед началом партии запрашивает размер поля `n × n` (чётное целое `n >= 4`); при ошибочном вводе повторяет запрос. `quit` или EOF завершают программу на этапе выбора размера.
- Отображает доску, количество фишек, выделяет допустимые клетки звёздочкой `*` и печатает отдельной строкой `* - допустимые ходы`.
- Приглашения к вводу: `черные(Black)>` и `белые(White)>`. Ввод `row col` с координатами от 1 до выбранного `n`; `undo` для отмены; `quit` или EOF для завершения.
- При автоматическом пропуске указывается причина; по завершении игры выводится победитель или ничья.

## Проверки

Тесты должны покрывать захваты по 8 направлениям, несколько направлений за один ход, невозможные ходы без переворота, границы поля, копирование, пустой журнал, защитные копии массивов, пропуск, окончание при пустых клетках, ничью, победу белых и чёрных, undo после пропуска и окончания, а также генеративные проверки целостности счёта и обратимости партии.
