# Отелло (Реверси)

Реализация настольной стратегической игры **Отелло (Реверси)** на Java 21 с консольным интерфейсом для двух игроков.

Логика разделена между `Board` (игровое поле, допустимые ходы и перевороты фишек) и `Game` (очерёдность, завершение партии и история). Реализованы неизменяемые ходы `Move`, глубокое копирование состояния, отмена ходов `undoLast()`.

## Правила

- Стандартное поле — **8 × 8**, можно создать игру на любом чётном поле размера **4 × 4** и больше.
- В центре находятся четыре фишки: две чёрные и две белые. **Чёрные ходят первыми**.
- Игрок выбирает свободную клетку. Ход допустим, если после размещения фишки хотя бы в одном из восьми направлений между новой и уже стоящей фишкой игрока находится непрерывная цепочка из одной или более фишек соперника.
- Все захваченные цепочки переворачиваются, в том числе в нескольких направлениях одновременно.
- **Если у следующего игрока нет допустимых ходов, его ход автоматически пропускается**. Пропуск не записывается как `Move`: ход делает игрок, у которого есть хотя бы одно допустимое действие.
- **Если допустимых ходов нет у обоих игроков, партия завершена**, даже если остались пустые клетки. Побеждает тот, у кого больше фишек. При равном количестве объявляется ничья.

## Архитектура

| Тип | Ответственность |
| --- | --- |
| `Mark` | Метки `BLACK`, `WHITE`, `EMPTY`. |
| `Move` | Неизменяемый `record Move(int row, int col, Mark mark)`. |
| `GameState` | `BLACK_TURN`, `WHITE_TURN`, `BLACK_WON`, `WHITE_WON`, `DRAW`. |
| `Board` | Хранение фишек, вычисление захватов, переворот, легальные ходы, подсчёт фишек, копирование и низкоуровневый откат. |
| `Game` | Очередность, пропуск, определение окончания партии, история, `undoLast` и копирование. |
| `Main` | Консольная игра двух человек. |

Классы `Board`, `Game`, `Mark`, `Move` и `GameState` имеют **package-private** доступ. Их можно использовать в коде пакета `reversi`; класс `Main` содержит точку входа в приложение.

### Основные методы

```java
package reversi;

class Example {
    public static void main(String[] args) {
        Game game = new Game(); // 8x8; ход чёрных
        int[][] legal = game.availableMoves(); // [row, col], индексы с 0
        boolean accepted = game.apply(new Move(2, 3, Mark.BLACK));
        System.out.println(accepted);                // true
        System.out.println(game.state());            // WHITE_TURN
        System.out.println(game.score(Mark.BLACK));  // 4
        System.out.println(game.score(Mark.WHITE));  // 1
        int[][] flipped = game.lastFlipped();         // {{3, 3}}
        Move[] history = game.history();              // 1 ход
        game.undoLast();
        System.out.println(game.state());            // BLACK_TURN
    }
}
```

- `new Game()` — новая игра 8×8; `new Game(int size)` — поле `size × size` (чётный `size >= 4`); `new Game(Game other)` — независимая копия.
- `board()` — независимая копия `Board`; `history()` — новый массив ходов; `availableMoves()` — допустимые ходы текущего игрока в порядке строк и столбцов; `lastFlipped()` — координаты фишек, перевёрнутых **последним принятым ходом**.
- `apply(move)` — отклоняет любые некорректные ходы с результатом `false` и не изменяет состояние.
- `undoLast()` — откатывает размещение и **все** перевёрнутые фишки; восстанавливает очередь даже после автоматического пропуска или окончания партии.
- `score(mark)` — количество чёрных или белых фишек; для `EMPTY`/`null` возвращает `0`.

В Отелло победитель определяется количеством фишек после окончания партии. Метод `lastFlipped()` возвращает координаты фишек, перевёрнутых последним принятым ходом.

## Как запустить

**Требования:** JDK **21 или новее**. Gradle Wrapper включён в проект. При первом запуске Gradle требуется доступ к репозиториям для загрузки самого Gradle и тестовых зависимостей.

macOS / Linux:

```bash
./gradlew run
./gradlew clean test
./gradlew build
```

Windows:

```powershell
.\gradlew.bat run
.\gradlew.bat test
```

**Перед началом партии** программа запрашивает размер квадратного поля `n × n`: введите чётное целое число `n >= 4` (например, `4`, `8` или `10`). Если число некорректно, программа повторяет запрос. Введите `quit` для выхода до начала партии.

В консоли чёрные и белые фишки обозначены `B` и `W`, свободные клетки — `.`, допустимые ходы текущего игрока — `*`. Ход: `черные(Black)>` и `белые(White)>`. Команды `undo` и `quit` отменяют последний ход и завершают сессию соответственно.

### Компиляция без Gradle

```bash
javac -encoding UTF-8 -d out src/main/java/reversi/*.java
java -cp out reversi.Main
```

## Тесты

Файлы JUnit 5 + AssertJ:

- `BoardTest.java`: начальная расстановка, валидация размера и текста исключения, допустимые ходы, проверка всех восьми направлений, многократные и многолинейные перевороты, копирование, некорректные координаты, заполнение доски.
- `GameTest.java`: очередь ходов, счёт, валидация, автоматический пропуск, победы обоих цветов, ничья, завершение с пустыми клетками, восстановление фишек при отмене, копирование, генеративные партии и повторное воспроизведение после отката.
- `MainTest.java`: название игры, приглашения игроков, запрос размера поля (4×4, 8×8, 10×10), проверка корректности размера, подсказка о `*`, консольные команды, однобазовые координаты, ошибки ввода, завершение по EOF.

Тесты запускаются командой `./gradlew test`. Подробные правила и контракт находятся в [TASK.md](TASK.md).
